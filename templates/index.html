ABOUT PROJECT

Machine Learning Based AQI Prediction

Problem

Air pollution is a major environmental concern. This system predicts the Air Quality Index from pollutant concentration measurements.

Machine Learning

A Decision Tree Regression model is used to estimate AQI from twelve pollutant parameters.

Technology

Python, Flask, Pandas, Scikit-learn, HTML, CSS and JavaScript are used to build the application.
